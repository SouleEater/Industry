ЛОКАЛЬНАЯ ИГРА

Соберите свой стол

Игроки ходят по очереди на одном устройстве. Начало новой партии заменит текущее локальное сохранение.

Отдельный модуль: уголь увеличивает ставку. Без управляющих на аукцион добавляется одно предприятие.

После аукциона каждый игрок планирует линию. В «Цепочке» новые карты вставляются между старыми, а производство идёт слева направо.

Дополнительная настройка, не обязательное правило игры. Время даётся на ставку, выбор компенсации, весь план или всё производство одного игрока. По истечении — уведомление без штрафа. Перезагрузка не обнуляет отсчёт.
