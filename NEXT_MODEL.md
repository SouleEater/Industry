## Код, версии и запуск

`packages/domain/engine.mjs`: чистое детерминированное ядро. Фазы auction → settlement → planning → production → следующий раунд/finished. Правила prototype-0.2. `packages/application/session.mjs` мигрирует legacy prototype-0.1 с planning=false, productionChain=false, turnSeconds=0, чтобы не вставлять новую фазу в старый replay. Сохранять эту совместимость.

`packages/application/decision-clock.mjs`: часы с внедряемым now; deadline хранится в record.clock отдельно от команд. В domain нет Date.now/setTimeout. Будущий сетевой режим требует серверного контроля времени; текущий таймер локальный и рекомендательный.

Node.js >=22; внешних npm-зависимостей нет. `npm.cmd test`, `npm.cmd run build`, `npm.cmd run dev`. Сборка dist рассчитана на корень домена. Порт по умолчанию4173; в этой сессии новая версия работает на4174, поскольку старый процесс на4173 Windows не разрешила завершить. Запуск на другом порту: `$env:INDUSTRY_PORT = '4174'`, затем `npm.cmd run dev`. Проверять процессы, не завершать все Node-процессы. После перезапуска компьютера обычно доступен4173.
