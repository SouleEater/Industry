# Разбор пользовательского архива базовой игры

Дата исследования: 25.09.2026, упаковка обновлена 28.09.2026. Источник: предоставленный пользователем `индустрия.zip`. В репозитории исходные байты хранятся в четырёх файлах `research/archives/base-industry.zip.part001`–`part004`. Размер исходного ZIP: 173 951 728 байт. Скрипт `python scripts/archive_parts.py` восстанавливает единый ZIP без изменения содержимого и проверяет SHA-256. Манифест частей — `research/archives/base-industry.parts.json`; контрольные суммы архива и всех вложений — `research/base-import-manifest.json`. Git LFS заменён этим способом после двух сетевых обрывов загрузки большого объекта.

## Что изучено

Просмотрены все 122 отдельных изображения, 73 слайда пяти PPTX и 21 страница двух PDF. PPTX отрисованы установленным Microsoft PowerPoint в режиме чтения с отключёнными макросами; исходники не изменялись. PDF отрисованы PDFium. Итого в основном каталоге: **31 пара предприятий + 5 стартовых + 5 персонажей = 41 запись и 72 изображения игровых сторон**. Дополнительный слайд-заготовка и альтернативные PDF сохраняются в архиве. Они не засчитываются как недостающие физические экземпляры. Изолированные иллюстрации не доказывают наличие отдельной карты и не задают её игровые свойства. В архиве также есть дубликаты портретов и посторонние изображения; они не включены в игровой каталог.

## Формат расшифровки

`packages/content/user-base-catalog.mjs` содержит расшифровку всех 41 записей: источник и слайды, компенсацию, последовательность обычного и улучшенного производства, стартовую строку или способность, замечания и ссылки на изображения. Названия предприятий технические. Имена персонажей взяты из текста, а не определены по портретам.

Слиток обозначает металл, куб с раскалёнными фрагментами — уголь, бочка — нефть, шестерёнка — жетон модернизации. Цветные строки активны; серые строки обычной стороны становятся активными после улучшения. В `upgraded` перечислены **все** активные строки улучшенной стороны, поэтому нельзя повторно добавлять к ним `basic`.

`limit: null` означает «кратность в данном макете не указана», а не бесконечность. Для компенсации рецепт записан на одну единицу диска. `starting` содержит только верхнюю строку стартовой карты, без общих ресурсов подготовки из правил. `playable: false` и `officialVerified: false`: каталог предназначен для сверки, его нельзя выдавать движку как готовую колоду.

## Обнаруженные расхождения и пробелы

1. В базовом комплекте 36 предприятий, а в полноразмерных PPTX найдено 31. Требуются ещё **5 пар** либо пояснение автора макетов о составе. Семейства и официальные ID ещё не установлены.
2. PPTX 009, слайды 3–4: производство `2 угля → 1 нефть`, максимум 2 раза. PDF 008, стр. 3–4: `1 уголь → 1 нефть`, максимум 1 раз. У PDF нет отдельной пары для обоих вариантов; считать его просто копией PPTX нельзя.
3. PPTX 009, слайды 7–8: у производства `1 металл → 1 жетон модернизации` нет надписи кратности. PDF 008, стр. 5–6, показывает ×1. В каталоге сохранено неизвестное значение PPTX, а альтернативное свидетельство — в примечании.
4. PPTX 024, слайды 1–2: первая производственная стрелка также без кратности. Улучшенная продажа потребляет именно **2 металла** за 2 денег, ×4. На других картах встречается 1 металл за 2 денег — они не унифицированы.
5. PDF 008, стр. 11–12: сначала улучшенная сторона, затем обычная. Соответствующие PPTX 009, слайды 13–14 идут в обратном порядке. Пары определены по цвету активных эффектов, а не только по чётности номера.
6. Первый персонаж называется «Поль» в PDF 115 и «Эварист» в PPTX 116. Способность одинакова: раз за фазу производства 2 угля за повтор своей карты.
7. Артур в обоих файлах уже имеет одновременную постановку дополнительной двойки с другой ставкой на другую карту. В реализации потребуется атомарная команда двух ставок.
8. Макеты используют собственное оформление и символ денег; соответствие каждой карты официальному экземпляру ещё не доказано. Сканы «Интербеллума» не получены.

## Подключение к приложению

В веб-приложение добавлен отдельный экран `/apps/web/catalog.html`: разделы, поиск, обычная/улучшенная сторона, увеличение, текст эффектов и примечания. В него включены 72 JPEG, экспортированные из PowerPoint. Их SHA-256 и происхождение находятся в `research/base-web-assets.json`. Учебный игровой пакет и сохранения не изменены.

## Воспроизведение импорта

Для запуска приложения Python, PowerPoint и скачивание большого архива не требуются: веб-изображения уже включены обычными файлами Git. Для повторной обработки исходников:

```powershell
python scripts/archive_parts.py
python scripts/import-base-scans.py
powershell -File scripts/render-base-slides.ps1
python scripts/export-card-images.py
```

Сборка ZIP требует только стандартную библиотеку Python. Импорт/экспорт изображений требует Pillow. Рендер презентаций требует установленный PowerPoint на Windows. При первичном импорте можно передать `--source "путь/индустрия.zip"`; без него скрипт восстановит архив из частей. Существующий архив не заменяется. `research/imported/` — восстанавливаемые временные данные, исключённые из Git. `research/base-source-text.json` — вспомогательная выгрузка текста; сама по себе для расшифровки недостаточна.

## Следующая разработка

Получить пять недостающих пар и разрешить расхождения; затем привязать каталог к официальным слотам и семействам. После этого создать отдельно валидируемый игровой пакет, реализовать способности промышленников и разные стартовые предприятия. Для каждой способности и для производства с разным порядком строк добавить сценарии, основанные на конкретных картах. Не превращать отсутствие источника в случайно сгенерированные значения.
