# Бесплатный хостинг на Oracle Cloud (Always Free)

Пошаговая инструкция для небольшой компании друзей. Итог: сервер «Индустрии» работает круглосуточно по адресу `https://ваше-имя.duckdns.org`, вход по коду приглашения. Общая справка по настройкам и безопасности — в [07-deployment.md](07-deployment.md).

Названия пунктов в консоли Oracle и на сайтах могут немного отличаться: интерфейсы меняются. Условия бесплатного тарифа сверьте на сайте Oracle перед регистрацией.

## Что понадобится

- банковская карта для проверки при регистрации (деньги не списываются, пока вы остаётесь в пределах бесплатных ресурсов);
- бесплатный домен третьего уровня (ниже — DuckDNS): для HTTPS нужно имя, по одному IP сертификат не выдаётся, а пароли по обычному HTTP передавать нельзя;
- 30–40 минут.

## 1. Регистрация в Oracle Cloud

1. Откройте страницу бесплатного тарифа Oracle Cloud и зарегистрируйтесь.
2. **Домашний регион выберите внимательно: его потом нельзя поменять.** Берите регион поближе к друзьям, где нет очереди на ресурсы.

## 2. Создать виртуальную машину

«Compute → Instances → Create instance»:

- **Image:** Ubuntu 24.04 (или 22.04).
- **Shape:** «Ampere» `VM.Standard.A1.Flex`, 2 OCPU и 12 ГБ памяти — это максимум бесплатного ARM. Если Oracle отвечает «Out of capacity», повторите позже, смените домен доступности или возьмите `VM.Standard.E2.1.Micro` (1 ГБ памяти; этого хватает, скрипт сам добавит swap).
- **Networking:** оставьте публичный IPv4.
- **SSH keys:** нажмите «Save private key» и сохраните файл, он понадобится для входа.

## 3. Открыть порты 80 и 443 в сети Oracle

«Networking → Virtual cloud networks → ваша сеть → Security lists → Default → Add ingress rules»: два правила, источник `0.0.0.0/0`, протокол TCP, порты назначения `80` и `443`. Порт 22 (SSH) уже открыт.

Фильтр на самой машине (iptables) скрипт ниже откроет сам.

Чтобы адрес не менялся при пересоздании машины, закрепите постоянный публичный IP (в консоли — «Reserved public IPs»; проверьте, что он входит в бесплатные ресурсы вашего тарифа).

## 4. Домен: DuckDNS

1. Зайдите на duckdns.org (вход через существующий аккаунт), создайте поддомен, например `myindustry`.
2. В поле «current ip» укажите публичный IP вашей виртуальной машины и сохраните.
3. Ваш адрес: `myindustry.duckdns.org`.

## 5. Настроить машину одной командой

Подключитесь по SSH (в Windows PowerShell; файл ключа — тот, что вы скачали):

```bash
ssh -i путь\к\ключу.key ubuntu@ПУБЛИЧНЫЙ_IP
```

На машине:

```bash
git clone https://github.com/SouleEater/Industry.git
cd Industry
bash scripts/vm-setup.sh myindustry.duckdns.org invite
```

Скрипт установит Docker, добавит swap на слабой машине, откроет порты, создаст `.env` со случайным секретом и **кодом приглашения**, соберёт и запустит сервер. Первая сборка занимает несколько минут. Код приглашения покажет в конце; позже его можно посмотреть так:

```bash
grep INVITE_CODE .env
```

## 6. Первый вход

1. Откройте `https://myindustry.duckdns.org` (сертификат выпускается при первом обращении, это занимает до минуты).
2. «Войти» → «Регистрация»: логин, пароль и код приглашения.
3. «Онлайн» → «Создать стол» → отправьте друзьям ссылку из комнаты ожидания и код приглашения для регистрации.

Когда все друзья зарегистрировались, регистрацию можно закрыть: в `.env` поставьте `REGISTRATION=closed` и выполните `docker compose up -d`. Уже созданные пользователи продолжат входить.

## 7. Картинки «Интербеллума» (по желанию)

Без них карты дополнения рисуются схематично, всё остальное работает. Если у вас есть PDF издателя и сервер только для узкого круга друзей, извлеките картинки на своём компьютере и отправьте на машину:

```bash
python scripts/extract-official-pdfs.py "C:/путь/к/PDF"
scp -i ключ.key -r apps/web/assets/official ubuntu@ПУБЛИЧНЫЙ_IP:~/Industry/apps/web/assets/
```

Затем на машине `docker compose up -d --build`. Помните: публично раздавать такие картинки нельзя (см. [07-deployment.md](07-deployment.md#картинки-издателя)); оставляйте `REGISTRATION=invite` или `closed`.

## 8. Резервные копии

Все данные — одна база SQLite в томе Docker. Ежедневная копия на самой машине:

```bash
crontab -e
# добавьте строку:
17 4 * * *  cd ~/Industry && bash scripts/backup.sh >> ~/backup.log 2>&1
```

Копии лежат в `~/backups` (хранятся 14 последних). Раз в неделю скачивайте свежую на свой компьютер:

```powershell
scp -i ключ.key ubuntu@ПУБЛИЧНЫЙ_IP:~/backups/industry-*.db .
```

Восстановление: остановить сервер (`docker compose stop app`), скопировать файл копии в том как `/data/industry.db`, запустить снова.

## 9. Обновление и обслуживание

```bash
cd ~/Industry
git pull
docker compose up -d --build     # данные сохраняются
docker compose logs -f app       # логи сервера
docker compose exec app node server/admin.mjs users
docker compose exec app node server/admin.mjs reset-password Логин
```

## Если что-то не работает

- **Сайт не открывается вообще.** Проверьте оба слоя файрвола: правила в Oracle (шаг 3) и iptables на машине (делает скрипт). Проверка с вашего компьютера: `curl -I http://myindustry.duckdns.org`.
- **Ошибка сертификата или зависает HTTPS.** DNS ещё не обновился (подождите пару минут) или закрыты порты 80/443. Логи: `docker compose logs caddy`.
- **Сборка обрывается («Killed»).** Не хватило памяти: проверьте, что swap создан (`free -h`), и повторите `docker compose up -d --build`.
- **Oracle «Out of capacity».** Бесплатные ARM-машины бывают нарасхват: повторите позже или возьмите микро-машину (шаг 2).
- **Вход не сохраняется, «Устаревшая страница».** Открывайте сайт по `https://` и по тому домену, который указан в `DOMAIN`: сервер сверяет адрес запросов.

## Важно про бесплатный тариф

Oracle забирает бесплатную машину, если 7 дней подряд её загрузка (процессор, сеть и для ARM память) ниже 20%. Для небольшой игры это реально. Поэтому делайте резервные копии (шаг 8) и держите под рукой эту инструкцию: пересоздать машину и восстановить базу можно за полчаса.
