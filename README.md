# Индустрия — цифровой стол

Веб-версия настольной игры Ивана Лашина «Индустрия» и дополнения «Интербеллум» для компьютера и телефона: игра на одном устройстве и онлайн-партии с друзьями через сервер с регистрацией и входом.

> Проект не связан с издателем. Правила и компоненты принадлежат ООО «Мир Хобби»; см. [замечание о картинках](#картинки-издателя).

**Для продолжения разработки:** [PROGRESS.md](PROGRESS.md) — состояние, решения и карта кода; [NEXT_MODEL.md](NEXT_MODEL.md) — инструкция для следующей сессии.

## Что уже есть

- **Игра по правилам**: аукцион дисками 1–4, компенсации, планирование линии, производство, модернизация, 4 раунда, итог с тай-брейками; вдвоём — против агента базовой игры.
- **Дополнение «Интербеллум»**: 24 новых предприятия (поставки, текстовые и постоянные эффекты), стартовые предприятия дополнения, университеты и жетоны управляющих, диск переменного капитала, промышленники (включая «Соседа»).
- **Режимы**: свободное производство или «Цепочка» (старые карты закреплены, слева направо).
- **Интерфейс**: карты рисуются по данным (после улучшения переворачиваются), понятные подсказки шага, панель вашего промышленника, окно раздачи, справка с правилами, журнал ходов, каталог карт.
- **Онлайн**: регистрация и вход, комнаты на 2–4 игроков, приглашение по коду или ссылке, ходы проверяет сервер, обновления приходят сразу (SSE). Партия сохраняется на сервере — можно закрыть вкладку и вернуться.
- **Безопасность**: пароли в scrypt, сессии в HttpOnly-cookie, защита от CSRF и перебора паролей, строгая политика содержимого страницы, скрытая от игроков колода. Подробности — [docs/07-deployment.md](docs/07-deployment.md).

Чего пока нет: игры в одиночку с двумя агентами, варианта «Рост капитала», пятого игрока, таймера хода, восстановления пароля по почте и входа через внешних провайдеров. Полная оригинальная колода базы не сверена: в каталоге 31 предприятие из 36 ([подробности](docs/06-base-archive.md)).

## Быстрый старт

Нужны Node.js **22.13+** (лучше 24) и Python 3 с Pillow и numpy. Внешних npm-зависимостей нет.

```bash
python -m pip install pillow numpy
npm run table:images     # упаковывает картинки карт (файл в git не хранится)
npm run table            # собирает dist/table.html
npm start                # сервер с входом и онлайн-играми: http://127.0.0.1:8080
```

Достаточно только сыграть на одном устройстве, без входа и сервера:

```bash
npm run table:serve      # http://127.0.0.1:4174
```

В Windows двойной щелчок по `START-TABLE.cmd` делает то же самое. Файл `dist/table.html` можно открыть и напрямую, но сохранение партии между запусками там может не работать.

### Картинки издателя

Иллюстрации карт «Интербеллума», университетов, стартовых предприятий и портреты промышленников берутся из PDF издателя, которых в репозитории нет. Если PDF у вас есть:

```bash
python -m pip install pymupdf
python scripts/extract-official-pdfs.py "C:/путь/к/папке/с/PDF"   # затем повторите table:images и table
```

Без них стол работает целиком: эти карты рисуются схематично. Права на картинки принадлежат издателю, поэтому папка `apps/web/assets/official/` исключена из git; не выкладывайте такой сервер публично без разрешения (см. [docs/07-deployment.md](docs/07-deployment.md#картинки-издателя)).

## Как играть по сети

1. Запустите сервер (`npm start`) или откройте чужой.
2. Зарегистрируйтесь или войдите (кнопка «Войти» / «Онлайн»).
3. «Онлайн» → «Создать стол» (выберите правила) → отправьте друзьям код или ссылку.
4. Когда за столом от 2 до 4 человек, хозяин нажимает «Начать игру».

Ход делает только тот, чья очередь; чужие ходы приходят на экран сами.

## Развернуть для игроков

Готовая схема с HTTPS (Docker + Caddy):

```bash
cp .env.example .env     # заполните DOMAIN, SESSION_SECRET, режим регистрации
docker compose up -d --build
```

Полная инструкция — настройки, обновление, резервные копии, сброс пароля, безопасность и ограничения: **[docs/07-deployment.md](docs/07-deployment.md)**.

## Разработка и проверка

```bash
npm test     # ядро правил, каталог, интерфейс (при установленном jsdom), сервер
```

Тесты интерфейса на jsdom пропускаются, пока он не установлен: `npm install --no-save jsdom`. Серверные тесты запускают настоящий сервер на свободном порту с временной базой.

Структура:

```text
server/                 сервер: вход, столы, ходы, рассылка событий, администрирование
packages/domain/        чистые правила и переходы (без браузера, сети и файлов)
packages/content/       каталог карт, дополнение, промышленники, жетоны
packages/application/   игровой сеанс и восстановление истории
apps/table/             интерфейс стола (ui.js) и онлайн-модуль (online.js)
apps/web/               первый учебный интерфейс и каталог карт
scripts/                сборка стола, упаковка и извлечение картинок, локальные серверы
tests/                  тесты правил, интерфейса и сервера
docs/                   исследование, ТЗ, архитектура, этапы, проверка, развёртывание
research/               исходные материалы, манифесты и место для новых сканов
```

Правила исполняет одно и то же ядро в браузере и на сервере: сборка `scripts/build-table.mjs` склеивает модули `packages/domain` и `packages/content` с интерфейсом, поэтому источник истины один.

## Полученные материалы

Исходный ZIP сохранён без изменения содержимого в четырёх файлах `research/archives/base-industry.zip.part001`–`part004`, каждый меньше 50 МБ. Для сборки единого архива выполните `python scripts/archive_parts.py` (Python 3.10+): скрипт проверит размер и SHA-256 каждой части. Для запуска приложения архив не нужен: изображения и расшифровка уже лежат обычными файлами. `research/base-import-manifest.json` содержит список вложений и SHA-256, `packages/content/user-base-catalog.mjs` — расшифрованные карты с номерами слайдов.

Сканы оригинальных компонентов кладите в `research/scans/incoming/` ([инструкция](research/scans/README.md)). [Реестр компонентов](research/component-register.json) содержит 86 официальных карточных мест и 15 мест управляющих; [манифест источников](research/source-manifest.json) — ссылки, версии и SHA-256 официальных PDF.
